# HO02: Modelagem Conceitual

## Conceitos Básicos

A modelagem conceitual refere-se à abstração de uma descrissão textual (minimundo) de requisitos e dados, para uma forma de representação gráfica das entidades, atributos e relacionamentos. Este conceito faz parte da etapa de projeto conceitual do BD, e comumente é adotado o **Diagrama de Entidade-Relacionamento** usando a notação de **Peter Chen**.
